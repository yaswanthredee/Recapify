# Recapify

**Recapify — Never Miss What Matters**

A native Android college project app for AI-assisted meeting catch-up. The signature feature is **I Joined Late**, which lets a student select how many minutes they missed and instantly see a structured catch-up with topics, key points, tasks, deadlines and suggested questions.

## Android app

- Native Android Java UI
- Stylish dark AI-inspired interface
- Dashboard and meeting statistics
- I Joined Late catch-up flow
- Meeting upload picker
- Tasks and deadlines
- Ask Recapify demo assistant
- Analytics screen
- Offline demo content for reliable college presentation

## APK

GitHub Actions builds the debug APK automatically. Open the latest **Build Recapify APK** workflow run and download the `Recapify-APK` artifact.
